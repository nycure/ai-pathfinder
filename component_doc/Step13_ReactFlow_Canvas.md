# Step 13: React Flow Canvas & Custom Nodes

## Component Overview
This is the core visual component of the AI Pathfinder. It renders the personalized curriculum generated by the AI as an interactive, zoomable, and pannable 2D map.

## Architectural Purpose
Standard lists are boring and fail to convey the non-linear, branching nature of tech skills. 
1. **Spatial Learning**: By rendering skills as a DAG, learners instantly see what unlocks what (e.g. "If I learn React, I unlock Next.js").
2. **Custom Nodes (`MilestoneNode.tsx`)**: We don't want generic boxes. We want sleek, glassmorphic cards showing the milestone's status (Locked, Available, Completed), estimated time, and skills acquired.
3. **Custom Edges (`PrerequisiteEdge.tsx`)**: The edges connecting nodes are animated and glowing if a path is actively available, guiding the user's eye.

## Detailed Implementation Specifications
1. **`frontend/src/components/roadmap/MilestoneNode.tsx`**:
   - A React Flow custom node component.
   - Extracts `data` of type `RoadmapNodeData`.
   - Renders a shadcn `Card` wrapped with Tailwind glassmorphism styles (`bg-card/50 backdrop-blur-md`).
   - Uses `lucide-react` icons to show status (e.g., a Padlock for `locked`, a CheckCircle for `completed`).
   - Renders standard React Flow `Handle` components for edge connections.
2. **`frontend/src/components/roadmap/PrerequisiteEdge.tsx`**:
   - Uses React Flow's `getBezierPath`.
   - Adds custom glowing SVG paths for active edges.
3. **`frontend/src/components/roadmap/RoadmapCanvas.tsx`**:
   - Connects to the Zustand `useRoadmapStore`.
   - Passes `nodes` and `edges` directly into `<ReactFlow>`.
   - Defines `nodeTypes = { customMilestoneNode: MilestoneNode }`.
   - Implements `onNodeClick` which triggers `setActiveNode` in the store, opening the XAI side drawer.
